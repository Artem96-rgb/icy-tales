## IcyTales – Non-commercial Furniture Shop

IcyTales is a modern, non-commercial furniture shop web application built with React and Next.js. It demonstrates interactive UI components, responsive design, and form handling with real-time validation.

## Features
    • Product catalog with categories and filtering  
    • Interactive UI components and sliders  
    • Forms with validation using Zod and React Hook Form  
    • Toast notifications for user interactions  
    • Responsive layout built with Tailwind CSS  
    • State management using Zustand  
    • Component library built with shadcn/ui  
    • Mock API implementation for retrieving data from a test environment  
    • Data fetching and caching with TanStack Query


## Technologies & Tools

### Frameworks & Libraries
    • Next.js – React framework for server-side rendering and routing
    • React – Front-end library for building user interfaces
    • React Hook Form – Form handling and validation  
    • Zod – Schema-based validation  
    • Zustand – State management  
    • Swiper – Responsive sliders  
    • Lucide React – Icon library  
    • React Toastify – Toast notifications

### Styling & UI:

    •	Tailwind CSS￼ – Utility-first CSS framework
    •	Tailwind Merge (tailwind-merge) – Merge Tailwind class names safely
    •	Stylelint – Linting for CSS/SCSS

## Development Tools

    •	TypeScript – Type-safe development
    •	ESLint – JavaScript/TypeScript linting
    •	Prettier – Code formatting

## Quick Start

    # Install dependencies
    pnpm install

    # Run dev server
    pnpm dev

    # Build for production
    pnpm build

    # Start production server
    pnpm start
